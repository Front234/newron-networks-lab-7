## Лабораторная работа "Обработка временных рядов с помощью нейронных сетей"

## Структура репозитория

-`lab7Lite.ipynb` – ноутбук для задания Lite: прогнозирование временного ряда акций Лукойла с использованием полносвязных сетей, Conv1D и LSTM
-`lab7Pro.ipynb` – ноутбук для задания Pro: улучшение прогнозирования временного ряда с помощью расширенных признаков и увеличенного окна просмотра в прошлое
-`lab7Ultra_Pro.ipynb` – ноутбук для задания Ultra Pro: прогнозирование трафика сайта компании и анализ автокорреляции сигнала
-`lab7Pytorch.ipynb` – ноутбук для задания Lite:прогнозирование временного ряда акций Лукойла с использованием полносвязных сетей, Conv1D и LSTM. Выполнено с помощью Pytorch

## Требования

Для запуска ноутбуков рекомендуется использовать **Google Colab**. Все необходимые библиотеки предустановлены в Colab.
